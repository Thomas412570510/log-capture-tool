# 這是建立新案例的範本資料夾

當您有新的資料需要處理時，請依照以下步驟：

1. 複製這個 `_template` 資料夾。
2. 將複製出來的資料夾重新命名為 `caseXX`（例如 `case02`, `case03`）。
3. 修改資料夾內的檔案：
   - `email_template.md`: 填入信件主題、寄件者與內文。
   - `system.log`: 貼上您的系統日誌（腳本會自動抓取裡面帶有 error, fail, exception 等字眼的行數）。
4. （可選）您可以隨意更改檔案名稱，只要副檔名維持 `.md`, `.txt` 或 `.log`，腳本都會自動抓取。
5. 回到最外層執行 `python main.py`，就會在 `output` 資料夾生成最新的報表與截圖了！
